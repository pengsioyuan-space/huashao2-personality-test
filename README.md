# 花少2人格测试

根据用户提供的小程序截图制作的独立静态备份网站。

## 功能

- 复刻暖橙旅行杂志风格
- 5 道旅行情境题
- 5 种旅行人格结果
- 自动计分和结果明细
- 测试记录保存在浏览器本地
- 手机与桌面端自适应
- 无后端、无登录、无广告

## 本地预览

直接打开 `index.html`，或运行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

> 本测试仅供娱乐，不构成专业心理评估。节目及人物名称归其权利人所有，本项目与节目官方无关。

迁移原因：使用自定义域名入口访问，避免继续依赖云开发默认访问地址；平台提示是否消失需要部署后实际核验。

- HTTP 网关域名：sioyuan.site；触发路径：/hs2-personality
- 资源类型：静态托管；选择现有实例 hs2-personality；路径透传关闭。
- 先部署本仓库静态文件，再添加上述独立路由；保留现有根路由和其他站点路由。
- 根路径访问和本地预览仍保留；网关带前缀访问时显式设置资源基路径，兼容 URL 末尾没有斜杠的情况。
- 题目、选项、计分、结果及浏览器存储逻辑未修改。没有新增后端接口，也没有修改网关配置。
